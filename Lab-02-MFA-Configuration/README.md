Project 2: Microsoft Entra ID – Multifactor Authentication (MFA)

Project Overview

This hands-on lab focused on configuring and testing Multifactor Authentication (MFA) using Microsoft Entra ID and the Microsoft Authenticator app.

The purpose of this project was to understand how organizations add an additional layer of security to user accounts and protect against unauthorized access.

Objectives

Create a test user in Microsoft Entra ID.

Register the test user with Microsoft Authenticator.

Configure authentication methods.

Test the MFA sign-in experience.

Understand how MFA strengthens identity security.

Tools & Technologies

Microsoft Entra ID

Lab Implementation

Step 1: Create a Test User

Created a test user account in Microsoft Entra ID to simulate an employee identity within an organization.

Step 2: Register Microsoft Authenticator

Registered the test account with Microsoft Authenticator and verified that authentication methods were available.

Step 3: Review Authentication Methods

Reviewed the available authentication options, including:

Sign-in notifications

One-time password codes

Passkey setup

Passwordless sign-in options

Step 4: Test MFA Authentication

Used the test account to perform a sign-in and MFA verification process.

Step 5: Document Results

Captured screenshots and a screen recording to demonstrate the account selection and Microsoft Authenticator configuration.

Results & Key Takeaways

Gained hands-on experience with Microsoft Entra ID user management.

Practiced registering an identity with Microsoft Authenticator.

Learned how different authentication methods support account security.

Developed a better understanding of MFA and identity verification.

Security Takeaway

Multifactor Authentication reduces the risk of unauthorized account access by requiring additional verification beyond a password. It is an important security control in modern Identity and Access Management environments.
